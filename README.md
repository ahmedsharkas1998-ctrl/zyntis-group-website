# Zyntis Group — AI Systems & Connected Infrastructure

Official website for **Zyntis Group**, engineered with a sovereign black-and-gold luxury aesthetic and real-time 3D WebGL interactive storytelling.

## Overview
Zyntis Group architects, integrates, and deploys unified AI systems into actual business workflows. The website showcases the company's capabilities, operational methodology, interconnected system architecture, and client engagement framework.

## Key Features
- **Tech-Organic Voxel Tree & Terrain**: Custom procedural Three.js WebGL engine with GPU vertex displacement, instanced rendering, dynamic electrical pulses, and organic torch lighting across the landscape.
- **Scroll-Driven Narrative Chapters**: 7 camera waypoints synchronizing 3D perspectives with sequential typography and operational methodology.
- **The System Visualization**: Dynamic particle-based business infrastructure orchestration featuring conversational agents, inbound channels, CRM integration, and analytics.
- **Responsive Black & Gold Aesthetic**: Editorial typography (Inter, Source Serif 4, JetBrains Mono) with high-contrast obsidian backgrounds, champagne gold accents, and fluid transitions.
- **Interactive Contact Flow**: Clean engagement form and direct consultation request pathways.

## Tech Stack
- **Three.js** (WebGL 3D graphics, Post-processing, GTAO, UnrealBloom)
- **HTML5 / CSS3** (Custom properties, responsive flex/grid layouts, view transitions)
- **Vanilla Modern JavaScript (ES Modules)**
- **Lenis Smooth Scroll**
